date: 2024-12-05
categories: [tools]
---

Presentations written in HTML or Markdown, rendered in a browser.

Slides live in a text file, which means they diff, review and version like code. Speaker notes, PDF export, and it scales to a phone screen.

If you keep your slides in a repo next to the thing you are presenting, this is the tool. Host it on GitHub Pages for free.
